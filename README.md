# Tavşan Düşüşü

three.js ile yazılmış, tek dosyalık Helix Jump tarzı tarayıcı oyunu.

**Oyna:** https://fuattikir.github.io/tavsan-dususu/

Aşağı indikçe on beş ayrı yerden geçiyorsun — Şafak'tan Kandil Mağarası'na.
Her yerin kendi göğü, ışığı, platform süsleri ve kule deseni var. Üç zorluk
modu: Kolay, Orta, Zor.

3D modeller poly.cam ile fotoğraftan üretildi. Müzik: yirmi klasik parça,
hepsi kamu malı — kayıt değil, oyunun kendi sentez piyanosu çalıyor
(nota verileri Mutopia Project dizgilerinden).
